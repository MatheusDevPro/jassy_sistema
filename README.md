# 🐍 Sistema Jassy (`sistema_jassy`)

Sistema de gerenciamento e automação em Python desenvolvido com interface gráfica e foco em controle operacional, cadastro de produtos (incluindo formulários de marcas) e rotinas organizacionais.

🌐 **Repositório:** [MatheusDevPro/sistema_jassy](https://github.com/MatheusDevPro/jassy_sistema)

---

## 🚀 Tecnologias Utilizadas

O projeto é construído integralmente utilizando tecnologias de desenvolvimento desktop e automação:

- **Python (100%)** — Linguagem principal para a lógica de negócio, automações, manipulação de dados e interfaces.
- **Tkinter** — Framework gráfico utilizado para a construção das telas do sistema (como o cadastro e formulários de produtos e marcas).
